# Ideas

Plans for work we may build later. An idea records the problem, the evidence
for it, and a plan someone can pick up. Nothing here is scheduled. Defects that
CI hits today belong in [`issues/`](../issues/README.md), not here.

Start each file with its status: `Not started`, `In progress` (with a link to
the branch or PR), or `Built` (with a link to what shipped). Line references
are to the commit named at the top of each file and will drift.
